## 1. 电机模型

在 dq 坐标系下（`ωe = P·ωm`）：

```
vd = Rs·id + Ld·did/dt - ωe·Lq·iq
vq = Rs·iq + Lq·diq/dt + ωe·Ld·id + ωe·λ
Te = 1.5·P·[ λ·iq + (Ld - Lq)·id·iq ]
J·dωm/dt = Te - B·ωm - TL
```

`id_ref = 0` 时 `Te = 1.5·P·λ·iq`，即转矩与 q 轴电流成正比。
本工程 `Ld < Lq`（反凸极），磁阻转矩项 `(Ld - Lq)·id·iq` 在 `id=0` 时为零；
若将来做 MTPA，需要把该项纳入。

仿真电机参数（`Subsystem/Interior PMSM` 块）：

| 参数 | 值 |
| --- | --- |
| `P` | 7 |
| `Rs` | 0.194 Ω |
| `Ldq` | `[9.7e-5, 1.2e-4]` H |
| `lambda_pm` | 0.0016 Wb |
| `mechanical` | `[J=5e-5 kg·m^2, B=1e-4 N·m·s/rad, Tf=0]` |
| 负载转矩 | 0（`Constant` 输入） |
| 逆变器 | `Average-Value Inverter`（平均电压模型，无开关纹波） |

## 2. 坐标变换

### 2.0 先用一句话说清楚

Clarke 和 Park 都是**平面上的坐标映射**，不改变电流本身，只是换一种写法：

- 电机三相绕组在空间上互差 120°，三相电流合成出来是一个**旋转的空间矢量**。
  因为三相三线制里 `ia + ib + ic = 0`，三个数里只有两个是独立的，所以这个矢量
  完全可以用平面上的一根箭头（两个数 `iα`、`iβ`）表示。
  **Clarke 就是把这个三轴描述换成二轴描述**，箭头本身没变。
- 这根箭头是相对**定子**画的（`α` 轴对齐 a 相绕组），电机一转，箭头就在平面上转，
  `iα`、`iβ` 都是正弦量。
- **Park 就是把同一根箭头换到转子的视角去看**：坐标轴跟着转子转，`d` 轴指向转子磁铁的
  一个磁极方向（N 极），`q` 轴超前 `d` 轴 90° 电角度。数学上就是乘一个旋转矩阵
  （`cosθ`、`sinθ`）。
- 换成转子视角后，稳态下 `id`、`iq` 变成**直流量**，PI 控制器才能做到无静差；
  如果一直用定子视角的正弦量去调 PI，稳态一定带着幅值和相位误差。

所以整套变换的意思就是：**把三相电流投影到转子磁铁的 N-S 轴上（`d` 轴，负责励磁）
和与它垂直的轴上（`q` 轴，负责出转矩）**。`id` 一般给 0，转矩全由 `iq` 出。
反 Park 是反方向：先定好想要的 `vd`、`vq`，再转回定子坐标，交给 SVPWM 变成占空比。

| 视角 | 坐标轴怎么取 | 电流分量 | 稳态时的波形 |
| --- | --- | --- | --- |
| 定子视角（Clarke 之后） | `α` 轴对齐 a 相绕组，`β` 轴超前 90° | `iα`、`iβ` | 正弦 |
| 转子视角（Park 之后） | `d` 轴对齐转子磁极（N 极），`q` 轴超前 90° 电角度 | `id`、`iq` | 直流 |

从 αβ 到 dq 的旋转角就是电角度 `θ`；转子转多快，坐标系就转多快，所以电流看上去就不动了。

下面的 2.1、2.2 是这两步的具体算式。

### 2.1 Clarke（`FOC contral/clerk变换`）

```
iα = ia
iβ = (1/√3)·(ia + 2·ib) = (1/√3)·(ib - ic)
```

推导（验证幅值不变）：设 `ia = I·cosθ`、`ib = I·cos(θ-120°)`、`ic = I·cos(θ+120°)`，则

```
ia + 2·ib = I·[cosθ + 2·cos(θ-120°)]
          = I·[cosθ - cosθ + √3·sinθ] = √3·I·sinθ
⇒ iβ = I·sinθ,  iα = I·cosθ
```

因此 `iα/iβ` 的模等于相电流峰值。只用 `ia`、`ib` 两相，隐含 `ia+ib+ic=0`（三相三线）。
源码注释里明确写了这一点，`ic` 只用于示波器，不参与运算。

### 2.2 Park / 反 Park

```
id =  iα·cosθ + iβ·sinθ
iq = -iα·sinθ + iβ·cosθ

vα = cosθ·vd - sinθ·vq
vβ = sinθ·vd + cosθ·vq
```

两组变换互为转置（正交矩阵的逆等于转置），保证功率/幅值口径一致。
注意：反 Park 与 Park 需要使用同一个 `θ`。本模型中两处都用 `θ_foc`（Supervisor 输出），
这是 5.7 节闭环成立的前提。

### 2.3 口径一致性检查清单

- [x] Clarke 与 Park 都是幅值不变，没有混入功率不变系数。
- [x] 电压与电流用同一套 Clarke 系数（`SVPWM` 直接把 `vα/vβ` 当相电压峰值用）。
- [x] 电角度与机械角速度在跨界处显式换算（`ωe = P·ωm`），见 5.8 节。
- [x] SVPWM 的 `Ts` 与控制器采样周期同为 `1e-4 s`。

## 3. SVPWM（`FOC contral/svpwm`）

### 3.1 扇区判定

```
vref1 = vβ
vref2 = (√3·vα - vβ)/2
vref3 = (-√3·vα - vβ)/2
N = (vref1>0) + 2·(vref2>0) + 4·(vref3>0)
```

`N = 3,1,5,4,6,2` 依次对应扇区 `1..6`；`N = 0/7`（零矢量）回落到扇区 1，
此时 `T1 = T2 = 0`，占空比三相等值，输出零矢量，不会产生错误电压。

### 3.2 作用时间

```
X = √3·Ts·vβ / Vdc
Y = Ts·(1.5·vα + 0.5·√3·vβ) / Vdc
Z = Ts·(-1.5·vα + 0.5·√3·vβ) / Vdc
```

按扇区查表得到相邻两个基本矢量的作用时间 `T1`、`T2`。等价于经典形式：
`T1 = (√3·Ts·|V|/Vdc)·sin(π/3 - θ')`、`T2 = (√3·Ts·|V|/Vdc)·sin(θ')`，
其中 `θ'` 是参考矢量在扇区内的相对角。

### 3.3 过调制处理

```
if (T1 + T2) > Ts:  k = Ts/(T1+T2);  T1 *= k;  T2 *= k
if T1 < 0: T1 = 0
if T2 < 0: T2 = 0
```

等比例缩放保持电压矢量角度不变、只压缩幅值（最小相位误差的过调制），代价是幅值失真，
好处是实现简单且不会因为饱和产生角度跳变。若改用六边形边界法可以把基波幅值多榨出约 5%，
本工程不需要。

`Vdc < 1e-6` 时被钳到 `1e-6`，避免除零。这是唯一的一处除零保护，`svpwm` 内部没有其它除法。

### 3.4 七段式对称 PWM 与占空比

```
Ta = (Ts - T1 - T2)/4      % 每周期两端零矢量的单侧宽度
Tb = Ta + T1/2
Tc = Tb + T2/2
```

`Tcm1..3` 按扇区重新排序（以扇区 1 为例 `Tcm1=Ta, Tcm2=Tb, Tcm3=Tc`），占空比

```
da = 1 - 2·Tcm1/Ts,  db = 1 - 2·Tcm2/Ts,  dc = 1 - 2·Tcm3/Ts
```

校验（满调制，`T1 = T2 = Ts/2`）：`Ta=0, Tb=Ts/4, Tc=Ts/2` →
`(da,db,dc) = (1, 0.5, 0)`，正是基本矢量 `V1(100)`，正确。
`Tcm` 的物理含义是"该相低电平持续时间"，中心对齐 PWM 下高电平时间 = `Ts - 2·Tcm`，
所以占空比可以写成上式。

## 4. 电流环（`FOC contral/PID Controller`, `PID Controller1`）

### 4.1 结构

```
id_err = id_ref - id      iq_err = iq_ref - iq
vd = PI_d(id_err) + Vd_ff(ωe, iq)
vq = PI_q(iq_err) + Vq_ff(ωe, id) + inj_out
```

`Vd_ff = -ωe·Lq·iq`、`Vq_ff = ωe·λ + ωe·Ld·id` 正好抵消 1 节方程中的交叉耦合项和反电动势项，
把被控对象近似解耦成 `vd → id`、`vq → iq` 两个一阶环节 `1/(Ls+R)`。

前馈使用的电感/磁链参数必须与电机模型一致；本工程源码注释记录了从 `1.5e-5` 改到 `1.2e-4` 的过程，
说明前馈参数失配确实造成过问题（详见调试纪要 9.1 节）。

### 4.2 参数与限幅

| 环 | `Kp` | `Ki` | 输出限幅 | 积分限幅 |
| --- | --- | --- | --- | --- |
| d 轴 | 0.2 V/A | 0.0002 V/(A·s) | ±9.5 V | ±9.5 V |
| q 轴 | 0.2 V/A | 0.05 V/(A·s) | ±9.5 V | ±9.5 V |

- 比例增益对应带宽量级 `Kp/L ≈ 0.2/1.2e-4 ≈ 1.7e3 rad/s`，周期 `Ts=1e-4 s` 下可稳定
  （`ω·Ts ≈ 0.17`，未逼近离散化极限）。
- 积分非常弱：`Ki/Kp` 分别为 `1e-3` 与 `0.25 rad/s`，即积分零点在 0.0016 Hz / 0.04 Hz。
  这是"以 P 为主、靠前馈顶住反电动势"的整定风格，代价是带载时仍有静差。
- `AntiWindupMode = none`，靠"积分器限幅 + 输出限幅"双重钳位防止饱和累积。
- d/q 两轴 `Ki` 相差 250 倍，没有物理依据，属于分别试凑的结果，见调试纪要 9.6 节。

## 5. 低速无感：高频注入（`FOC contral/PLL`）

### 5.1 为什么需要

`E = ωe·λ`，零速时反电动势为零，任何基于反电动势的观测器都失去信息。
高频注入利用**凸极**（`Ld ≠ Lq`）把转子位置"编码"进高频电流的幅值/相位里，
在零速和低速仍然可观测。

### 5.2 高频阻抗模型

设估计坐标系相对真实转子坐标系的误差为 `Δθ = θ - θ̂`。同一电流矢量在两个坐标系间的
电感矩阵为（`L0 = (Ld+Lq)/2`，`L1 = (Ld-Lq)/2`）：

```
L̂ = R(Δθ)·diag(Ld, Lq)·R(-Δθ)
  = [ L0 + L1·cos2Δθ    L1·sin2Δθ     ]
    [ L1·sin2Δθ          L0 - L1·cos2Δθ ]
```

`det(L̂) = Ld·Lq`，其逆为

```
L̂⁻¹ = 1/(Ld·Lq) · [ L0 - L1·cos2Δθ   -L1·sin2Δθ    ]
                   [ -L1·sin2Δθ        L0 + L1·cos2Δθ ]
```

关键点：**误差信息只出现在 `2Δθ` 上**，所以后面必须除以 2。

### 5.3 注入与响应（d 轴注入）

本工程把注入加在 **d 轴指令电压**上（`MATLAB Function2` 的 `inj_out` → `Add1` → `vd`）：

```
vd_inj = Vh·sin(ωh·t),  Vh = 0.2 V,  ωh = 2π·1000 rad/s
```

忽略电阻，`dî/dt = L̂⁻¹·[Vh·sin(ωh t), 0]ᵀ`，积分一次得

```
id̂ = -Vh·cos(ωh t)/(ωh·Ld·Lq) · (L0 - L1·cos2Δθ)
iq̂ = +Vh·cos(ωh t)/(ωh·Ld·Lq) · L1·sin2Δθ
```

即：d 轴高频电流里带一个"与位置误差无关的大直流偏置 `L0`"和一个"随 `2Δθ` 变化的项"，
q 轴高频电流里只有 `L1·sin2Δθ` 项。`L1` 为负（`Ld < Lq`），符号在整定时要注意。

### 5.4 解调（`BPF → ×sin(ωh t) → LPF`）

```
ia,ib,ic → Clarke → iα,iβ → HFI_Park(θ̂) → id̂, iq̂
id̂ → BPF → ×sin(ωh t) → LPF → Ed
iq̂ → BPF → ×sin(ωh t) → LPF → Eq
```

带通滤波器（`DiscreteFilter2/4`，`fs = 10 kHz`）：

```
num = [0.0826, -0.0826]
den = [1, -1.398, 0.6578]
```

实算频响（按上述系数直接代入 `H(e^{jωTs})`，`fs = 10 kHz`）：

| 频率 | \|H\| | 相移 |
| --- | --- | --- |
| 50 Hz | 0.010 | +88.5° |
| 500 Hz | 0.125 | +68.4° |
| 847 Hz | 0.246 | +25.2° |
| 1000 Hz | 0.244 | +2.2° |

极点 `0.699 ± j0.411`，模 0.811、角 0.532 rad ⇒ 中心频率约 **847 Hz**，半功率带宽约 670 Hz。
带通中心与 1 kHz 注入频率不匹配（见调试纪要 9.5 节），当前只是"能用"。

解调后低通（`DiscreteFilter1/3`）：

```
num = [0.0591]
den = [1, -0.9409]     % 直流增益 = 1，截止 ≈ 94 Hz
```

### 5.5 误差提取（`PLL/MATLAB Function1`）

```
Ed_c = clamp(Ed, ±10)      % 电流量纲，A
Eq_c = clamp(Eq, ±10)
ε = 0.5·atan2(Eq_c, Ed_c)
```

把 5.3 的结论代入（把 `cos(ωh t)` 的幅值记为 `k`，两支路 `k` 相同）：

```
Ed ≈ k·(L0 - L1·cos2Δθ)
Eq ≈ k·(-L1·sin2Δθ)
ε = 0.5·atan2(-L1·sin2Δθ, L0 - L1·cos2Δθ)
```

`Δθ → 0` 时线性化：

```
ε ≈ (-L1/L0)·Δθ = (Lq - Ld)/(Lq + Ld)·Δθ = 0.106·Δθ   [rad/rad]
```

三个直接结论：

1. 误差信号被**衰减到约 10%**（因为凸极率只有 `Lq/Ld = 1.24`），
   所以跟踪环必须用很大的增益（`Kp = 1000`）才能获得可用带宽。
2. 轨迹 `(Ed, Eq)` 是一个圆心在 `(k·L0, 0)`、半径 `|k·L1|` 的圆，因此 `ε` 的幅值有硬上限：

   ```
   |ε| <= 0.5·asin(|L1|/L0) = 0.5·asin(1.15e-5/1.085e-4) = 0.053 rad
   ```

   即误差信号最大只有约 3°。它同时带来两个后果：
   - 速度指令的上限被锁死为 `Kp_h·|ε|max ≈ 53 rad/s`（电角速度），
     折合约 7.5 rad/s 机械——这是 HFI 只能用在这个转速以下的结构性原因，
     与融合门限 8 rad/s 在同一个量级；
   - `Δθ = 90°` 时 `Eq = 0`、`ε = 0`，出现**假锁定点**。
     所以 HFI 启动时初始误差必须小于 45°，否则可能锁到错误的角度上。
3. 用 `atan2(Eq, Ed)` 而不是只取 `Eq`：`Ed` 里含与角度无关的 `L0` 偏置，
   双轴一起送进 `atan2` 相当于把偏置自动归一化，小误差区近似线性、大误差区有界。

关于解调相位：纯电感下高频电流与注入电压相差 90°，用 `sin` 解调得到的直流项会被压到 0。
实际能解出来，是因为 `R/(ωh·L) = 0.194/(2π·1000·1.2e-4) = 0.257`，电流存在约 25% 的同相分量，
加上带通在 1 kHz 处的 +2.2° 相位。**这也是该方案对 `Rs`、`L`、注入频率敏感的原因**：
一旦参数漂移，解调增益跟着漂，等效环路增益也漂。

### 5.6 跟踪环（`PLL/PID Controller2` + `PLL/Integrator`）

```
ω̂ = sat( Kp_h·ε + Ki_h·∫ε , ±200 rad/s )      Kp_h = 1000 1/s, Ki_h = 20 1/s²
θ̂ = ∫ω̂ dt
```

结构上是"PI + 积分"，理论上属于类型 2 系统，对匀速旋转的稳态相位误差为零；
但 `Ki_h` 很弱（时间常数 `Kp_h/Ki_h = 50 s`），1 s 的测试窗口内积分作用有限，
实际表现更接近带速度相关静差的类型 1 环路。`±200 rad/s` 的输出限幅高于
5.5 节算出的 `53 rad/s` 结构上限，限制速度范围的主要因素是误差信号饱和。

小信号模型（`k_e = 0.106`）：`s² + k_e·Kp_h·s + k_e·Ki_h = 0`。
比例通道时间常数 `1/(k_e·Kp_h) ≈ 9.4 ms`，积分通道时间常数 `Kp_h/Ki_h = 50 s`，
即**比例通道主导快速收敛、积分通道几乎不起作用**。这解释了实测约 50 ms 的锁定时间，
也解释了为什么加速度一大就跟不上：环路没有有效的积分记忆去预估角度变化率。
（该结论由结构推导得出，定量带宽待扫频实测确认，见第 11 节。）

### 5.7 HFI 闭环的前提（调试纪要第 2 条）

`HFI_Park` 用的 `θ̂` 必须与 FOC 的 `θ_foc` 是同一个角度。若 FOC 用真实角度、
HFI 自己用估计角度，则注入的高频电压经反 Park 后落在**真实 d 轴**上，
而 HFI 以为它注在**估计 d 轴**上，两者的夹角就是当前误差；观测器看到的高频响应
与它假设的模型不一致，误差信号被污染，表现为大相位差或发散。
本工程两处都用 `θ_foc`（`park 变换#in:3`、`park反变换#in:3` 与 `PLL/in:1` 同源），闭环成立。

### 5.8 相位补偿（`PLL/MATLAB Function2`，当前未接线）

源码提供了一个固定相位补偿：`lag = atan2(a·sin(ωh·Ts), 1 - a·cos(ωh·Ts))`，
`a = 0.9686`，即上面 50 Hz 一阶低通的相位滞后在 1 kHz 处的取值，约 1.21 rad（69°）。
但该模块在最终模型里**没有连线**，HFI 输出的是 PLL 积分器的原始角度。
这是调试遗留：该补偿会把 HFI 角度再超前 69°，与实测不匹配，作者后来改用
`phase_compensation_adaptive` 只作用于磁观测（见 6.5 节）。保留源码是为了记录这段过程。

## 6. 高速无感：反电动势磁链观测（`FOC contral/Subsystem`）

### 6.1 反电动势重构（`calc_BEMF`）

```
Eα = Vα - Rs·Iα
Eβ = Vβ - Rs·Iβ
```

严格形式应为 `V = Rs·I + L·dI/dt + E`。源码注释说明"电感压降较小，且电感项会放大噪声"，
因此省略 `L·dI/dt`。代价是引入一个**与负载电流相关**的角度误差：

稳态下 `id = 0`，电流矢量沿 q 轴，被省略的项是 `j·ωe·Lq·iq`，方向沿 d 轴。
设真实反电动势幅值 `|E| = ωe·λ`，则估计的反电动势矢量被额外叠加了一个 d 轴分量：

```
Δφ ≈ atan( ωe·Lq·iq / (ωe·λ) ) = atan( Lq·iq / λ )
```

代入 `Lq = 1.2e-4`、`λ = 0.0016`：`iq = 5 A` 时 `Δφ ≈ 20.6°`。
注意这个误差**与转速无关、只与 iq 成正比**——因为分子分母都含 `ωe`。
正弦速度激励下 `iq` 随负载同频变化，于是角度误差表现为**与电流同频的摆动**，
这正是为什么仅靠提高 PLL 增益无法消除该相位差的原因。

另外：`Vα/Vβ` 取的是反 Park 的**指令电压**，不含逆变器死区与开关延时补偿，
真机上会再叠加一层与电流方向相关的误差。

### 6.2 低通滤波（`DiscreteFilter1/2`）

```
num = [1],  den = [1, -0.9686]      % fs = 10 kHz
```

这是一个"一阶低通"的未归一化形式，直流增益 `1/(1-a) = 31.8`，使用时要计入这个放大倍数；
其截止频率 `(1-a)/(2π·Ts) = 50.0 Hz`。误差信号被整体放大 31.8 倍后进入 PLL，
整定的增益里已经包含了这个因子。

离散一阶低通 `H(z) = (1-a)/(1-a·z⁻¹)` 在频率 `ω` 处的相位滞后：

```
lag(ω) = arg(1 - a·e^{-jωTs}) = atan2( a·sin(ωTs), 1 - a·cos(ωTs) )
```

这就是 6.5 节相位补偿公式的来源（由上式直接得到）。

### 6.3 归一化误差（`calc_Angle_Error`）

```
E_mag = √(Eα² + Eβ²)
if E_mag < 0.05: err = 0
else:
    err_raw = -Eα·cos(θ̂) - Eβ·sin(θ̂)     % = |E|·sin(θ - θ̂)
    err = sign(ω̂) · err_raw / E_mag      % → sin(Δθ)，归一化到 ±1
```

三件事：

1. **归一化**让环路增益不随转速（即反电动势幅值）变化。若直接用 `err_raw`，
   高速时环路增益正比于 `ωe`，低速时又太小，必须按速度调度增益才能稳定。
2. **乘 `sign(ω̂)`** 保证反转时误差符号正确，同一个 PLL 能双向工作。
3. **`E_mag < 0.05 V` 死区**：反电动势过小时直接输出 0，防止把噪声当误差积分。
   由 `|E| = P·λ·|ωm| = 0.0112·|ωm|` 反推，死区对应 `|ωm| < 4.5 rad/s`，
   即磁观测在 4.5 rad/s 以下**必然失效**——这是"必须用 HFI 补低速"的定量依据。

### 6.4 锁相环（`PID Controller2` + `Integrator`）

```
ω̂ = sat( Kp_o·err + Ki_o·∫err , ±100 rad/s )     Kp_o = 15000 1/s, Ki_o = 10 1/s²
θ̂_raw = ∫ω̂ dt
```

由于误差已归一化且低通直流增益 31.8，等效比例增益约 `15000×31.8 ≈ 4.8e5 1/s`，
积分等效时间常数 `Kp_o/Ki_o = 1500 s`。工程含义：

- 比例通道极"硬"，稳态相位误差被压到毫弧度量级，但一有扰动就容易撞 `±100 rad/s` 限幅；
- 积分作用在 1 s 量级的试验中基本不起作用，所以实际表现接近带静差的类型 1 环路；
- 调这个环路时，`Kp` 的可用范围很窄，这也是"磁观测在仿真里能跑、换参数就发散"的原因之一。

### 6.5 自适应相位补偿（`phase_compensation_adaptive`）

```
we    = ωm·P
lag_t = atan2(a·sin(|we|·Ts), 1 - a·cos(|we|·Ts))     % 6.2 节的严格滞后
base  = 0.85·lag_t                                   % 0.85：实测标定系数，无解析依据

|we| ≤ 350 rad/s (50 rad/s 机械)      → lag = base
350 < |we| ≤ 560 (50~80 rad/s 机械)   → lag 从 base 线性降到 0.2 rad
560 < |we| ≤ 700 (80~100 rad/s 机械)  → lag 从 0.2 rad 线性降到 0.1 rad
|we| > 700                           → lag = 0.1 rad
we < 0                               → lag 取负
θ_comp = mod(θ̂_raw + lag, 2π)
```

三点必须写清楚：

1. 公式部分（`lag_t`）是针对低通滤波器相位的**严格补偿**，`0.85` 是人为打的折扣。
2. 高速段把补偿量压到 0.1 rad（5.7°），远小于滤波器理论滞后（700 rad/s 时约 63°）。
   高速段的相位误差主要来自 6.1 节的 `L·dI/dt` 缺失与采样延迟，低通只占其中一部分；
   按滤波器模型给满补偿会出现过补，环路稳定性下降。分段折线是
   "低补偿量保稳定、低速段全补偿保精度"的折中。
3. 该补偿依赖 `ωm` 与 `P`，正反转时符号必须翻转；源码里 `if we < 0: lag = -lag` 就是这一步。

`0.85 / 0.2 / 0.1` 三个常数当前**无解析依据**，属于试凑值，需按调试纪要 11 节的方案标定。

## 7. 中速融合（`FOC contral/MATLAB Function3` / `Supervisor_Final`）

### 7.1 为什么要融合

| 区间 | HFI | 磁观测 |
| --- | --- | --- |
| 低速（< 8 rad/s） | 误差信号强，可用 | `\|E\|` 低于死区，不可用 |
| 中速（8~15） | 反电动势开始淹没注入，误差被污染 | 可用，但纹波/相位误差随电流变化 |
| 高速（> 15） | 解调出来是噪声，发散 | 可用，需相位补偿 |

两个观测器**都不干净的重叠区**必须融合，否则任何单点切换都会踩到某一方的失效边缘。

### 7.2 权重调度

```
W_fuse_up = 15,  W_fuse_dn = 8        % 机械 rad/s
|ωm| >= 15 : θ_foc = θ_comp           % 完全用磁观测
|ωm| <= 8  : θ_foc = θ_hfi            % 完全用 HFI
8 < |ωm| < 15:
    α = (15 - |ωm|)/(15 - 8), clamp [0,1]      % HFI 权重
    s = α·sin(θ_hfi)  + (1-α)·sin(θ_comp)
    c = α·cos(θ_hfi)  + (1-α)·cos(θ_comp)
    θ_foc = atan2(s, c)
```

两个门限与两个观测器各自的有效区间对应：5.5 节算出 HFI 的结构速度上限约 7.5 rad/s 机械，
所以 8 rad/s 以下才让 HFI 完全接管；磁观测的死区在 4.5 rad/s（6.3 节），
两者之间必须有一段重叠才能平滑过渡，这就是 8~15 rad/s 融合区的位置来源。

### 7.3 为什么用 sin/cos 加权而不是线性加权

角度是圆周量。线性加权 `α·θ_hfi + (1-α)·θ_comp` 在 `θ` 跨过 `0/2π` 时会出现
`2π` 的跳变（例如 `θ_hfi = 0.01`、`θ_comp = 6.27`），融合输出直接跳到 3 rad 附近，
FOC 坐标系瞬间错位。

`(sin, cos)` 加权等价于**两个单位矢量的加权和再取相角**（圆均值）：

```
v = α·u_hfi + (1-α)·u_comp
θ_foc = arg(v),   |v| = √(α² + (1-α)² + 2α(1-α)cos δ)
```

- 两个角度相差 `δ` 时，融合角落在两者之间的加权位置，跨零连续，不会跳变；
- `|v|` 会略小于 1（`δ = 2°` 时 `|v| ≈ 0.9998`），只影响归一化，不影响相角；
- 它**不能**消除两者共有的系统偏差，也**不能**把 `δ` 消除为零——`δ` 本身必须靠 6.5 节的
  相位补偿压下去。融合只是把"阶跃"变成"渐变"。

### 7.4 为什么必须避免硬切换

硬切换会在 `θ_foc` 上产生 `δ = 0.5°~2°`（8.7~35 mrad）的阶跃。后果链：

```
θ_foc 阶跃 → Park 坐标系跳变 → id/iq 反馈跳变 → 电流误差跳变
          → PI 输出跳变 → vq 跳变 → 转矩冲击 → 转速波动 → 观测器误差变大 → 发散
```

同时 `dθ_foc/dt` 出现冲激，任何用角度差分做速度估计的地方都会被污染。
这就是作者观察到"直接切换就发散"的机理。

### 7.5 预热注入（`inj_gain`）

```
W_inj_max = 15  →  |ωm| <= 15 : g = 1.0
W_inj_min = 25  →  |ωm| >= 25 : g = 0.3
15 < |ωm| < 25 : g = 0.3 + (25-|ωm|)/10·0.7     % 线性过渡

inj_out = Vh·sin(ωh t)·g
```

- 高速段把注入降到 0.3（即 0.06 V）而不是 0：保证 PLL 不失锁、带通滤波器状态不衰减，
  再次进入低速区时不需要重新收敛（省掉约 50 ms 的锁定过程）。
- 代价是残余载波会污染磁观测。定量估算（`|E| = P·λ·|ωm|`、低通在 1 kHz 处 `|H| = 0.115`）：

```
残余纹波 ≈ (Vh - Rs·I_hf)·|H| = (0.2 - 0.194×0.328)×0.115 ≈ 15.7 mV
50 rad/s 时 |E| = 0.56 V  → 2.8% → 约 1.6° 角度纹波（g=1）
100 rad/s 时 |E| = 1.12 V → 0.8% → 约 0.46°
g = 0.3 时按比例降到 0.5°/0.14°
```

  这个量级在仿真里可以接受，但在真机上（叠加开关噪声）就是作者看到的
  "磁观测趋势正确但包络着高频正弦噪声"的来源。

### 7.6 当前判据的局限

Supervisor 只用 `|ωm|` 一个量做调度。问题是：同一转速下，轻载和重载的磁观测质量差别很大
（6.1 节的误差正比于 `iq`），`|ωm|` 无法区分。这就是"同一工况有时能切、有时不能"的原因。
改进方向见第 11 节。

## 8. 离散实现细节

| 项目 | 值 | 说明 |
| --- | --- | --- |
| 仿真求解器 | 固定步长 `1e-4 s` | `SolverName = FixedStepAuto`，`FixedStep = 1e-4` |
| 控制器采样 | `1e-4 s` 全部 | 每个 `PID Controller`、`MATLAB Function`、滤波器显式设为 `1e-4` |
| 采样保持 | 各环节前后均有 `Zero-Order Hold (1e-4)` | 保证控制器与对象同步，无代数环 |
| 电流采样 | `ia/ib/ic` 经 ZOH 后进 Clarke | 无 ADC 量化、无采样抖动 |
| 注入载波 | 1 kHz | 每周期 10 个采样点（`fs/fh = 10`），是正弦注入的下限 |
| 速度环降采样 | ZOH `1e-3 s` | 速度环 1 kHz |
| 初始状态 | `idq0 = [0 0]`、`theta_init = 0`、`omega_init = 0` | 零初值启动 |

数值安全清单：

- 除零：`svpwm` 有 `Vdc` 下限保护；其余除法分母为 `E_mag`（带 0.05 死区）、`Ld·Lq`（常数）。
- 饱和：电流 PI ±9.5 V、HFI 环 ±200 rad/s、磁观测环 ±100 rad/s、速度环 ±80 A、位置环 ±4000 rad/s、`Ed/Eq` ±10 A、电压矢量过调制缩放。
- 溢出：全部为双精度浮点，无整型运算。
- 角度：`mod(θ, 2π)` 在相位补偿后执行，`atan2` 返回 `(-π, π]`，FOC 内部用 `cos/sin` 对 2π 不敏感。

## 10. 三类判据的语义区分

同一个数字在不同阶段可能有不同含义，改之前必须确认语义：

| 判据 | 用途 | 语义 |
| --- | --- | --- |
| `\|ωm\|` | Supervisor 融合权重、注入增益 | **机械**角速度，rad/s |
| `\|ωe\|` | 相位补偿分段、`d_axis_ff/q_axis_ff` | **电**角速度，rad/s |
| `\|E\|` | 磁观测死区判据 | 反电动势幅值，V，等价于 `P·λ·\|ωm\|` |

`phase_compensation_adaptive` 内部做了 `we = wm·P`，`d/q_axis_ff` 内部也做了 `ωe = ωm·P`，
Supervisor 用的是 `wm`。三者不可混用；调试时若把机械速度直接喂给按电角速度整定的环节，
会差 7 倍，表现为"补偿看起来生效、实际方向反了"。

## 11. 没做的事

这个工程到验证结论为止，下面这些都清楚该怎么做、但没做（不属于"学算法"的目标）：

| 项 | 如果要做，怎么做 | 能回答什么 |
| --- | --- | --- |
| HFI 环带宽 | 在 `θ̂` 上叠加小扰动，测 `ε → θ̂` 频响 | 5.6 节的估算对不对 |
| 相位补偿标定 | 固定转速，扫 `iq = 0..8 A`，记 `θ_comp - θ` | 把 `0.85/0.2/0.1` 换成有依据的表 |
| `L·dI/dt` | 在 `calc_BEMF` 里补 `ωe·L·I` 做 A/B | 负载相关相位误差到底占多少 |
| Rs 灵敏度 | `Rs` 偏 ±20% | 低速观测器能容忍多大的参数漂移 |
| 带通重设计 | 按 1 kHz 重算 `num/den` | 注入上限能提高多少 |
| 加速极限 | 固定幅值 50 rad/s，频率 10 → 50 扫 | 重复验证 1500~2000 rad/s^2 的边界 |
