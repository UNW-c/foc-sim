# 调试与测试纪要

本文件记录从有感 FOC 到无感 FOC 全速域运行的过程中，实际遇到的问题、定位依据与解决方案。
写作目的有两个：一是给后来者一份可复用的排查路径，二是留下"问题是怎么被定位出来的"证据链。

记录格式固定为四段，缺一段就说明该问题还没有查清：

```
证据   —— 日志/波形/源码里能直接看到的现象，不写推测
推理   —— 从证据到原因的因果链，可以逐步复核
结论   —— 一句话的根因
方案   —— 做了什么修改，以及为什么这样改；若未解决，明确写"未解决"
```

---

## 0. 阅读前提

- 模型：`motor_simulink.slx`。有感方案是同一套电流环与 SVPWM，只需把角度来源换成
  真实电角度 `theta_e_measure`。
- 仿真环境：固定步长 `1e-4 s`，`Vdc = 24 V`，`id_ref = 0`，负载转矩 0，逆变器为平均电压模型。
- 所有波形来自 `测试波形/`，图例以 Scope 实际导出为准。
- 文中"机械速度"指 `ωm`（rad/s），"电角速度"指 `ωe = 7·ωm`。两者在文中都会显式标注。

## 1. HFI 在高速段发散

**证据**

- `100rad,20rad-s频率的测试波形.png`：速度在 0.3~0.5 s 之间卡在 0 附近，随后发散。
- `50rad，50rad-s频率的测试波形.png`：速度偏移到约 110 rad/s，角度信号呈高频交织，无法判读。
- 反电动势幅值 `|E| = P·λ·|ωm| = 0.0112·|ωm|`：50 rad/s 时 0.56 V，100 rad/s 时 1.12 V；
  而注入幅值固定为 `Vh = 0.2 V`。
- HFI 带通滤波器对基频只有约 -40 dB 抑制（50 Hz 处 `|H| = 0.010`）。

**推理**

1. 注入电压固定，转速升高后基波电压和基波电流都随之增大，注入源在总电压中的占比从
   50 rad/s 时的 13%（0.2 V 对约 1.5 V）继续下降。
2. 解调链是"带通 → 乘载波 → 低通"。带通对基频的抑制只有 -40 dB：
   基波 `iq = 5 A` 时漏进解调器的分量约 `5×0.010 = 0.05 A`，
   而有效高频分量约 `0.265 A×0.244 = 0.065 A`，两者同量级。
3. 于是 `Ed/Eq` 里的基频泄漏与 `2Δθ` 信号混在一起，`atan2` 输出不再表示角度误差，
   PLL 被噪声驱动 → 估计算出大相位差 → `θ_foc` 错 → 电流环注入错误 → 自激发散。
4. 转速越高，泄漏越大、有效分量越小，所以失效是单调的、不可通过调增益补救。

**结论**

HFI 的可用上限主要取决于注入信号与基频泄漏的信噪比。
本工程在 1 kHz 注入、0.2 V 幅值、-40 dB 带通的组合下，约 15 rad/s（机械）以上就不可信。

**方案**

- 高速段不再使用 HFI，改用反电动势观测；HFI 只保留 0.3 倍注入用于"保温"（见第 5 条）。
- 若要提高 HFI 上限，可选：提高 `Vh`（受电流纹波与噪声限制）、提高带通的基频抑制
  （代价是相位滞后变大）、提高注入频率（受采样率限制，见 9.5 节）。

**遗留**

- 带通中心实测 847 Hz、注入 1 kHz，两者不匹配；重新设计后信噪比还能再改善一档。

## 2. HFI 必须用自身角度闭环 FOC

**证据**

- 调试初期把真实电角度 `theta_e_measure` 送进 Park / 反 Park，HFI 内部用自己估计的 `θ̂`。
- 现象：HFI 输出要么有较大的固定相位差，要么是发散的高频噪声，无法收敛。

**推理**

1. 注入电压是按 `θ_foc` 经反 Park 旋转后加到三相上的。若 `θ_foc = θ_true`，
   注入落在**真实 d 轴**，而观测器认为它落在**估计 d 轴**。
2. 两个坐标系的夹角恰好就是待估的误差 `Δθ`。于是观测器看到的响应是
   "一个被 `Δθ` 调制过的激励"，而它假设的是"固定幅值激励"，模型与对象不一致。
3. 更严重的是闭环方向：观测器想把 `θ̂` 拉向 `θ_true`，但激励始终跟着 `θ_true` 走，
   `θ̂` 永远追不上，误差被不断放大，表现为大相位差或直接发散。
4. 这也解释了另一个现象：用真实角度做速度闭环时，HFI 能"看起来有输出"，
   但一旦切入融合、用 `θ_foc` 做电流环，立刻发散。

**结论**

注入与解算必须在同一个坐标系里。`θ_foc` 既是 FOC 的工作坐标系，也是 HFI 的注入与解算坐标系。

**方案**

1. 观测器内部对 `αβ` 电流做 Park 变换到估计坐标系（`HFI_Park(Iα, Iβ, θ̂)`），
   得到估计系下的 `id̂/iq̂` 再做带通与解调。
2. FOC 的 Park / 反 Park 与 HFI 的 `θ̂` 同源（都来自 Supervisor 的 `θ_foc`）。
3. 结果：注入方向与解算方向一致，误差通道才是真正的 `Δθ`，环路闭合。

**遗留**

- 该约束在代码里没有断言保护。若将来改成"外部角度 + HFI 观测"，必须同时改这三处
  （Park、反 Park、HFI_Park），否则会重现本问题。建议在 Supervisor 里加一致性检查。

## 3. 有感 FOC 阶段的参数与极限问题

**证据**

- 前馈模块的源码注释记录了两轮参数修改：`Lq` 从 `1.5e-5` 改到 `1.2e-4`，`λ` 从 `0.0036`
  改到 `0.0029`，理由都是"与仿真模型一致"。
- 主模型的电流环 `Kp = 0.2`（d/q 相同），`Ki` 分别为 `0.0002` / `0.05`，输出限幅 ±9.5 V；
  电机块参数见 `docs/algorithm-design.md` 第 9 节。
- 调试中把 `Rs`、`Ld/Lq`、`λ`、`J`、`B`、负载转矩填错时，出现过的现象：转速卡死、
  电流环高频振荡、给定阶跃时电流冲击过大。

**推理**

1. 电流环的对象是 `1/(Ls+R)`。`Kp = 0.2` 时闭环带宽约 `Kp/L ≈ 1.7e3 rad/s`，
   在 `Ts = 1e-4 s` 下 `ω·Ts ≈ 0.17`，仍有裕度；若把 `L` 误填成 1.5e-5，同一 `Kp`
   对应的带宽升到 1.3e4 rad/s，`ω·Ts ≈ 1.3`，离散系统的相位裕度会被吃掉，
   表现为高频振荡。
2. 前馈项 `ωe·Lq·iq`、`ωe·λ + ωe·Ld·id` 用的是模型参数。参数不匹配时，前馈从补偿项变成
   附加扰动：d 轴出现与转速成正比的电压偏置，引起电流静差与转矩偏置，进而影响转速。
3. 速度环是纯 P：`J` 填大时响应变慢，填小时相对增益过大、容易振荡；
   `B` 或负载转矩不准确时稳态转速对不上，限幅长期饱和，最终卡死。
4. 所以有感阶段的调试时间主要花在参数与对象的匹配上，控制结构本身很少需要改。

**结论**

有感 FOC 的调试顺序：先辨识电机参数，再整定电流环，最后整定速度/位置环。
参数与对象不一致时，先修正参数再动算法。

**方案**

- 建立参数核对表，逐项对照数据手册/实测（见 `docs/algorithm-design.md` 第 9 节）。
- 电流环整定用 `Kp = ωc·L`、`Ki = ωc·R`（`ωc` 取 `1/(5~10)·1/Ts`），再按波形微调。
- 前馈参数与对象参数必须用同一份来源；本工程直接把手册值同时写进电机块和前馈模块。

**遗留**

- 当前模型里 `λ = 0.0016 Wb` 与数据手册反推值（约 0.03~0.06 Wb 量级）不自洽，
  速度/转矩的绝对值不可当真，只用于算法相对比较。详见 9.3 节。

## 4. HFI 成立的前提：必须存在凸极

**证据**

- `Ld = 9.7e-5 H`、`Lq = 1.2e-4 H`，凸极率 1.24，`(Lq-Ld)/(Lq+Ld) = 0.106`。
- 把 `Ld = Lq` 设置后（等电感），HFI 输出的角度完全无法锁定，只会缓慢漂移或随机跳变。

**推理**

1. 由 `docs/algorithm-design.md` 5.2、5.3 节的推导，解调后的 q 轴分量
   `Eq ∝ L1·sin2Δθ`，其中 `L1 = (Ld-Lq)/2`。
2. `Ld = Lq` 时 `L1 = 0`，`Eq ≡ 0`，而 `Ed ∝ L0` 与 `Δθ` 无关，`atan2(0, L0) ≡ 0`。
   观测器的误差信号恒为零 → PLL 没有任何位置信息，输出由初值和噪声决定。
3. 凸极越弱，误差增益 `(Lq-Ld)/(Lq+Ld)` 越小，越容易被噪声淹掉。
   本工程 0.106 已经偏弱，全靠 `Kp = 1000` 顶住。
4. 表贴式电机（SPM，`Ld ≈ Lq`）不能用这种 HFI。可行替代：利用磁饱和制造小信号凸极
   （注入 d 轴电流改变饱和程度）、INFORM 法、或直接改用编码器/霍尔。

**结论**

HFI 对电机凸极有明确要求；凸极率低于约 1.1 时误差信号很小，可用性差。

**方案**

- 建模时显式设置 `Lq > Ld`，并在文档里标明这是为 HFI 构造的凸极。
- 验证实验（待做）：把 `Interior PMSM` 的 `Ldq` 改成等值，重跑 50/10 工况，
  预期 HFI 失锁、融合角度退化到只剩磁观测（低速失效）→ 作为"HFI 依赖凸极"的直接证据。

**遗留**

- 当前凸极是人为设定的，不是真机 M3508 的实测值。真机若是表贴式转子，
  这套 HFI 方案需要重新评估。

## 5. 融合段的四个具体问题

融合段（8~15 rad/s）是两个观测器**都不干净**的区间，这里的坑最多。

### 5.1 磁观测在仿真可用、在硬件低速不可用

**证据**：仿真里 8~15 rad/s 磁观测输出正常；真机在这个转速段 PWM 开关噪声的电压幅值
与反电动势同量级甚至更大。

**推理**：磁观测用 `E = V - Rs·I`。真机的 `V` 含开关纹波与死区误差，
`I` 含采样噪声；两者相减后的 `E` 在低速时只剩几十 mV，被噪声淹没。
本工程用平均电压模型，天然没有这一项，所以仿真"看起来"能用到更低转速。

**结论**：仿真给出的磁观测下限是乐观值，真机的下限更高，融合区必须整体上移。

**方案**：仿真里保留 8/15 门限，同时在文档中标注"真机需要重标"；
真机上应先做死区补偿与电流采样同步，再谈低速磁观测。

### 5.2 简单加权会同时继承两个偏差

**证据**：两个观测器输出都存在与速度/电流相关的相位偏差，且方向、大小不同；
直接加权后，融合角度与真实角度仍有可见偏差，并且偏差随速度缓慢变化。

**推理**：加权平均只能压低**独立的随机噪声**（`σ_f = √(α²σ1² + (1-α)²σ2²)`），
不能抵消**系统性偏差**。若两者分别带 `δ1`、`δ2` 的固定偏差，
融合结果是 `δ(α)`，仍然偏离真实值，只是偏差随 `α` 平缓变化。
所以"先融合、后补偿"的顺序是错的，必须先把两个观测器的偏差各自压小。

**结论**：融合不解决精度问题，只解决**切换连续性**问题。

**方案**：融合只负责过渡；两个观测器的相位误差分别用各自的补偿环节处理（第 7 条）。

### 5.3 两个观测器存在 0.5°~2° 的相位差，硬切换必然阶跃

**证据**：在两者同时工作的区间，`θ_hfi` 与 `θ_comp` 的差在 0.5°~2°（9~35 mrad）之间，
且差值随转速和负载变化；直接切换时电流出现冲击，严重时发散。

**推理**：`θ_foc` 阶跃 `δ` → Park 坐标系跳变 → `id/iq` 反馈跳变 →
电流 PI 立刻响应 → `vq` 阶跃 → 转矩冲击 → 转速波动 → 观测器误差进一步变大。
同时 `dθ_foc/dt` 出现冲激，污染所有基于角度微分的量。

**结论**：任何"单点阈值硬切换"都会把相位差变成阶跃扰动，必须做连续过渡。

**方案**：sin/cos 加权（圆均值），详见 `docs/algorithm-design.md` 7.3 节。
过渡带宽 7 rad/s（8→15），保证 `θ_foc` 连续且导数有界。

### 5.4 HFI 注入给磁观测引入包络噪声

**证据**：HFI 工作时，磁观测的角度虽然跟随真实角度变化，但上面叠着高频正弦包络，
`θ_comp` 不可直接用于闭环。

**推理**：注入电压 `Vh` 也在磁观测的 `Vα/Vβ` 里；`E = V - Rs·I` 只能部分抵消它
（`Rs·I_hf` 只有 `Vh` 的约 32%）。残余分量经 50 Hz 低通后仍有约 `15.7 mV`，
相对 50 rad/s 时的 `|E| = 0.56 V` 约 2.8%，折合约 1.6° 角度纹波；
转速越低、纹波占比越大。

**结论**：HFI 与磁观测之间存在耦合（注入是这套方案的必要代价），需要在幅值和时间占比上做限制。

**方案**：

- 高速段把注入降到 0.3 倍（残余纹波按比例降到约 0.5°）；
- 磁观测的 50 Hz 低通是最终防线，截止频率不能再提高（提高会放进更多载波）；
- 若要进一步降低耦合，可在磁观测的 `V` 通道做载波陷波，代价是额外相位滞后。

### 5.5 HFI 每次进入工作区需要约 50 ms 收敛

**证据**：每次速度由高速进入 HFI 工作区，`θ_hfi` 需要约 0.05 s 才与真实角度对齐；
激励加速度越大，越来不及收敛，直接发散。

**推理**：HFI 跟踪环的比例通道时间常数约 9 ms，但积分通道极弱
（`Kp/Ki = 50 s`，见 `docs/algorithm-design.md` 5.6 节）。进入工作区时 `θ̂` 与真实角度
存在较大初始误差，环路只能靠比例通道把它拉回来，且没有"速度记忆"去预估角度变化率。
50 ms 是"从初始误差拉到可接受范围"的经验值，不是稳态指标。
另外还有一个结构上限：归一化后的误差信号 `|ε| <= 0.053 rad`，
所以 HFI 能指令的最高电角速度只有 `Kp·|ε|max ≈ 53 rad/s`（≈7.5 rad/s 机械）。
这说明加速度增大后跟踪失败的原因：误差信号已经饱和，继续提高增益帮助有限。

**结论**：限制 HFI 的是**收敛速度**。

**方案**（本工程采用）：

1. **预热**：高速段把注入幅值降到 0.3 而不是 0，PLL 不失锁，进入低速区时误差已接近 0，
   省掉重锁过程。
2. **不完全关闭**：注入始终存在，带通滤波器状态不衰减，解调相位不跳变。
3. **连续融合**：即使残余误差不为零，也通过圆均值平滑过渡，避免阶跃。

**代价与遗留**：预热注入会持续给磁观测引入纹波（5.4 节），0.3 就是这两者的折中值；
该值目前是试凑，缺少"重锁时间 vs 纹波"的定量曲线。

## 6. 关于无感 FOC 的性能定位

**证据**

| 工况（幅值/频率） | 机械加速度峰值 | 结果 |
| --- | --- | --- |
| 50 / 10 | 500 rad/s^2 | [OK] |
| 50 / 20 | 1000 rad/s^2 | [OK] |
| 100 / 15 | 1500 rad/s^2 | [OK] |
| 100 / 20 | 2000 rad/s^2 | [FAIL] 过零段失锁 |
| 50 / 50 | 2500 rad/s^2 | [FAIL] 直接发散 |

**推理**

1. 五个用例的失效边界与加速度峰值单调对应，与幅值、频率单独都不单调，
   说明限制量是**角加速度**而不是转速。
2. 角加速度越大，HFI 在过零段需要跟踪的角度变化率越大；而 HFI 能指令的角速度被
   误差信号饱和锁在约 53 rad/s 电角速度（≈7.5 rad/s 机械），
   超过这个值后，FOC 会在一段时间内使用偏差较大的角度，可能进一步失稳。
3. 反电动势观测在过零段完全失效（`|E| < 0.05 V` 死区，对应 `|ωm| < 4.5 rad/s`），
   这段只能由 HFI 承担，于是加速度上限就是 HFI 的收敛能力上限。
4. 用"锁定时间 / 激励周期"作为可用性判据：50/10 为 0.08、100/15 为 0.12、
   100/20 为 0.16、50/50 为 0.40。比值越大越接近极限，与实测一致。
5. 100 rad/s 已超过 3508 在 24 V 下的空载转速（482 rpm ≈ 50.5 rad/s）。
   用超出硬件包络的工况去要求算法，本身就是错误的测试设计。

**结论**

无感 FOC 的动态性能主要受低速观测器的收敛速度限制。
验收标准需要按无感方案的特点单独设定。

**方案与认知**

- 工程上绝大多数无感应用（风机、泵、压缩机）都是单向、稳态、无需速度闭环的工况，
  正好避开加速度和过零问题；这就是它们敢去掉传感器的原因。
- 机器人关节、轮毂电机普遍用"电机端编码器 + 输出端编码器"的双编码器有感方案，
  因为需要高频换向、力矩闭环和零速保持。
- 如果一定要在动态工况用无感，需要更强的观测器（EKF、滑模、自适应磁链观测）
  和更高的采样率；继续调整 HFI 参数的改善空间有限。

## 7. 相位补偿：提高 PLL 增益不能替代补偿

**证据**

- 磁观测的 `E` 先经 50 Hz 一阶低通再进 PLL；低频段 PLL 增益再大，
  `θ_comp` 与真实角度之间仍有稳定相位差，且该差值随转速和 `iq` 变化。
- 把 `Kp_o` 从 15000 继续加大，相位差改善有限，反而出现高频抖动与限幅饱和。

**推理**

1. 低通引入的相位滞后属于乘性环节的相位，提高增益无法消除：
   `lag(ω) = atan2(a·sin(ωTs), 1 - a·cos(ωTs))`，在 50 rad/s（`ωe = 350 rad/s`）时约 47°。
   增益只能加快环路"追赶"，不能改变稳态相位差。
2. 另有一部分误差来自 `L·dI/dt` 被省略：`Δφ ≈ atan(Lq·iq/λ)`，
   50 rad/s、`iq = 5 A` 时约 20.6°。这一项与 PLL 增益完全无关，且随负载变化，
   正弦激励下表现为角度误差与电流同频摆动。
3. 提高 `Kp_o` 会把低通残余的载波纹波一起放大，撞上 `±100 rad/s` 限幅，
   于是出现"增益越大越抖"的现象。

**结论**

相位误差需要按各自的机理分别补偿。

**方案**

- 低通滞后用解析式补偿：`lag = atan2(a·sin(ωe·Ts), 1 - a·cos(ωe·Ts))`（严格推导）；
- 实测发现补偿量取理论值的 0.85 更稳，高速段进一步降到 0.2/0.1 rad；
- 正反转时补偿量取负（`we < 0 → lag = -lag`）。

**遗留**

- `0.85 / 0.2 / 0.1` 三个数没有解析依据，是试凑值；
- `L·dI/dt` 缺失造成的负载相关误差没有补偿，当前靠融合把它"稀释"掉；
- 建议按 `docs/algorithm-design.md` 第 11 节的方案做 `Δφ(iq)` 标定表。

## 8. 正弦注入 vs 方波注入

**证据**

- 最初使用高频方波注入：解调困难、可用激励上限低。
- 改成正弦注入：需要在 PLL 内部生成同频载波、用载波相乘解调、再加带通和低通，
  结构变复杂；实际运行时对基频干扰的抑制效果不理想（见第 1 条的定量估算）。

**对比**

| 维度 | 方波注入 | 正弦注入（本工程） |
| --- | --- | --- |
| 频谱 | 宽，含大量低次谐波 | 集中在 `ωh` 及边带 |
| 解调 | 与符号函数相乘，可用电流差分直接提取 | 需要正交/同相载波相乘，再滤波 |
| 载波相位 | 不敏感（边沿自同步） | 敏感，受带通/低通相位影响 |
| 采样要求 | 需要在高频边沿精确采样，或用前后两拍电流差 | 每周期至少 8~10 点（本工程 10 点） |
| 基频干扰 | 谐波落点低，易与基频重叠 | 依赖带通抑制，本工程仅 -40 dB |
| 电流纹波 | 大 | 小 |
| 实现复杂度 | 解调窗口对齐难 | 载波生成与相位补偿难 |

**结论**

两种方案没有绝对优劣：方波在低采样率下更容易做"差分式"解调，但对时序要求苛刻；
正弦对时序友好，但对滤波器相位和基频抑制敏感。作者换成正弦的收益是
"注入上限提高、电流纹波变小"，代价是解调链复杂、对基频干扰更敏感。

**方案与遗留**

- 保留正弦方案，但把带通按 1 kHz 重新设计（当前中心 847 Hz）；
- 若要回到方波路线，建议先把采样率提到 20 kHz 以上并固定采样与边沿的对齐关系。

## 9. 补充分析（本次核对模型源码发现）

以下问题不在原始调试记录里，是从模型和源码直接读出来的，按"证据 → 影响 → 处理思路"列出。
这些 **都没有实施**，只是整理模型时的发现，备查用。

### 9.1 前馈参数历史与模型现值不一致

**证据**：`d_axis_ff` 注释写 `Lq = 1.2e-4`、"原先 1.5e-5"；`q_axis_ff` 注释写
`Ld = 9.7e-5`、`flux = 0.0016`、"原先 0.0036，改为 0.0029"。但电机块的
`lambda_pm = 0.0016`，注释里的 0.0029 已经过时。

**影响**：注释误导后来者；若照注释改回 0.0029，前馈反而失配。

**建议**：删除或更新历史注释，参数只保留一处来源（建议用 `model workspace` 变量统一管理）。

### 9.2 磁观测省略 `L·dI/dt` 造成负载相关相位误差

**证据**：`calc_BEMF` 只有 `E = V - Rs·I`。

**影响**：`Δφ ≈ atan(Lq·iq/λ)`，50 rad/s、5 A 时约 20.6°，与转速无关、与 `iq` 成正比。

**建议**：补上 `ωe·Lq·iq`、`ωe·Ld·id` 项，或改用带 `L` 的磁链观测器；先做 A/B 对比。

### 9.3 仿真电机磁链与数据手册不自洽

**证据**：模型 `lambda_pm = 0.0016 Wb`；手册 `0.3 N·m/A`、`24.48 rpm/V`，
反推磁链在 0.03~0.06 Wb 量级。同时电机块显示的 `Ke = 159.98`、`Kt = 0.07`
与 `lambda_pm = 0.0016` 也不能互相推出。

**影响**：反电动势偏小 → `E = V - Rs·I` 中 `Rs·I` 占主导
（50 rad/s、5 A 时 `Rs·I = 0.97 V`，`|E| = 0.56 V`），观测器对 `Rs` 极其敏感：
`Rs` 偏 10% 就相当于 0.097 V，约 17% 的反电动势误差。

**建议**：按手册重算 `λ` 并同步更新前馈与观测器参数；在此之前，所有速度/转矩结论
只做相对比较。这也是"真机上 Rs 温漂会让低速观测器漂移"的量化依据。

### 9.4 采样率与注入频率的比例偏低

**证据**：`fs = 10 kHz`，`fh = 1 kHz`，每周期 10 点；带通中心 847 Hz。

**影响**：解调相位分辨率 36°/点，载波相位误差会直接变成 `Ed/Eq` 的比例误差；
方波注入在此采样率下更难做。

**建议**：真机至少 20 kHz；仿真可先试 20 kHz 验证带宽是否提升。

### 9.5 HFI 带通中心与注入频率不匹配

**证据**：`den = [1, -1.398, 0.6578]` 的极点对应 847 Hz，`num = [0.0826, -0.0826]`。
1 kHz 处 `|H| = 0.244`、相移 +2.2°，847 Hz 处 `|H| = 0.246`、相移 +25.2°。

**影响**：幅值几乎没有损失，但相位随频率变化很陡（847→1000 Hz 变化 23°），
注入频率、电机电感、温度任一漂移都会改变解调增益与相位。属于"能用但不稳"的设计。

**建议**：按 `fh` 重新设计带通（双线性变换或直接极点配置），并把中心频率与
`Sine Wave` 的 `Frequency` 用同一个变量驱动。

### 9.6 电流环 d/q 两轴积分增益相差 250 倍

**证据**：d 轴 `Ki = 0.0002`，q 轴 `Ki = 0.05`，`Kp` 相同（0.2）。

**影响**：两轴动态不一致；d 轴几乎没有积分作用，`id` 的静差全靠前馈。
在 `id_ref = 0` 的工况下不明显，一旦做弱磁或 MTPA 就会暴露。

**建议**：先按同一套规则（`Ki/Kp = R/L`）整定，再针对 q 轴单独微调，并记录理由。

### 9.7 未接线 / 未启用模块

**证据**：`Subsystem2`（位置环）输出未连接；`pre_sync_selector`、`phase_compensation_hfi`
无连线；`sync_enable` 恒为 0；`ic_measure` 只进 Clarke 但函数内部未使用。

**影响**：读代码的人会以为这些功能在生效，实际没有。这正是"设了值但没生效"的典型陷阱。

**建议**：要么删掉，要么在模型里加注释/标签说明"预留"；交付版本只保留生效通路。

### 9.8 单判据调度的局限

**证据**：Supervisor 只用 `|ωm|` 决定权重与注入增益。

**影响**：同一转速下轻载/重载的磁观测质量差别很大（9.2 节），`|ωm|` 无法反映。
表现为同一工况有时能切、有时不能。

**建议**：增加第二判据，例如 `|E|` 的幅值、观测器残差 `|θ_hfi - θ_comp|` 的滑动均值；
当两观测器分歧过大时降低对应的权重，而不是死守速度门限。

### 9.9 变量命名与实际语义相反

**证据**：`W_inj_min = 25`、`W_inj_max = 15`，且 `|ωm| >= W_inj_min` 时给 0.3，
`|ωm| <= W_inj_max` 时给 1.0。"min" 对应的却是较大的速度阈值。

**影响**：极易在后续修改中把比较方向写反。

**建议**：改名为 `W_inj_off` / `W_inj_on` 或 `W_inj_hi` / `W_inj_lo`，并在注释里写清方向。

## 12. 复盘

1. **观测器的失效边界要量化，不要靠感觉。** 磁观测的死区可以直接算出来
   （`|E| < 0.05 V → |ωm| < 4.5 rad/s`），HFI 的上限可以用基频泄漏与有效分量的比值估出来。
   有了这两条线，融合门限才有依据，而不是试出来的数字。
2. **切换问题的本质是"两个估计量的偏差"，不是"两个信号的选择"。**
   先保证每个观测器自身准确，再谈融合；融合只负责连续性。
3. **"预热"是用稳态噪声换瞬态收敛。** 代价可量化（约 1.6° 纹波换掉 50 ms 重锁），
   这个取舍必须写进文档，否则后人会以为 0.3 是个随便填的数。
4. **动态性能的上限在低速观测器。** 高速观测器只影响稳态精度，过零和低速才决定
   能不能跟踪正弦/阶跃激励。这也是无感 FOC 在机器人关节上不流行的根本原因。
5. **模型参数错误会产生"算法错误"的假象。** 有感阶段的前馈改动记录证明，
   大量看起来像控制算法的问题，根因是参数与对象不一致。
